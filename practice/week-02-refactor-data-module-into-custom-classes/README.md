# Refactor Data Module into Custom Classes

## Task Brief
Convert reusable functions into a class-based design with methods, docstrings, and inheritance hierarchy for your capstone project.

## Scenario
Your data team needs a maintainable class-based API for data transformation. Refactor week 1 functions into a reusable DataProcessor class.

## Deliverables
- DataProcessor class with methods and docstrings
- Updated data_utils.py module

## Success Criteria
- Class encapsulates 3+ data transformation methods
- Inheritance or composition used appropriately
- All methods and class documented with docstrings
- Object Oriented Programming: DataProcessor class with 3+ methods encapsulating prior functions
- Object Oriented Programming: Inheritance or composition pattern demonstrated
- Object Oriented Programming: Docstrings on all methods and class
