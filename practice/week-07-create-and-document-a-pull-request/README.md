# Create and Document a Pull Request

## Task Brief
Create a PR merging a feature branch; write clear description and respond to review comments on your capstone.

## Scenario
Your data team reviews code before merging. Create a PR from your feature branch with clear documentation and engage in review feedback.

## Deliverables
- Pull request with descriptive documentation
- Review comment responses

## Success Criteria
- PR title and description clearly explain feature
- At least one review comment addressed
- PR linked in capstone repo
- Pull Requests: PR created with descriptive title and body
- Pull Requests: PR description explains changes and rationale
- Pull Requests: Responds to review comments with clarifications
