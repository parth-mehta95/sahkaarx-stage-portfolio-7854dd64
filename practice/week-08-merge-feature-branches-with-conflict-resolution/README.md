# Merge Feature Branches with Conflict Resolution

## Task Brief
Merge multiple feature branches into main with clean commit history; resolve merge conflicts and document resolution approach for your capstone.

## Scenario
Your data team needs to integrate multiple feature branches. Merge data_loading and data_transformation branches into main, resolve conflicts, and document the process.

## Deliverables
- Merged main branch with clean history
- Conflict resolution documentation
- Pull request with merge strategy notes

## Success Criteria
- All feature branches merged to main without errors
- Merge conflicts identified and resolved correctly
- Commit history shows intentional merge strategy (squash/rebase)
- Pull Requests: Successfully merge 2+ feature branches with resolved conflicts
- Pull Requests: Document conflict resolution approach in commit messages or PR description
- Pull Requests: Maintain clean, linear commit history using squash or rebase strategy
