# Initialize Git Repo and Practice Core Commands

## Task Brief
Set up Git repository for capstone project; make initial commit with scaffold; practice add, status, and commit workflows.

## Scenario
Your data team needs version control for the capstone project. Initialize a Git repo, commit the project scaffold, and practice core commands.

## Deliverables
- Initialized Git repository with initial commit
- Demonstrated add/status/commit workflow

## Success Criteria
- Repository contains .gitignore and project scaffold files
- Commit history shows meaningful initial commit message
- git status and git log output confirm proper staging
- Repository Setup: Git repository initialized with .gitignore and initial commit
- Basic Commands: git add, git status, and git commit commands executed correctly
