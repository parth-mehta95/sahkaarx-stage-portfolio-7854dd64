# Create Feature Branches and Practice Meaningful Commits

## Task Brief
Build feature branches for data loading and transformation; commit with descriptive messages on each branch.

## Scenario
Your data team needs clean commit history and organized feature work. Create feature branches for data loading and transformation modules with meaningful commits.

## Deliverables
- Feature branches for data_loading and data_transformation
- Commit history with descriptive messages

## Success Criteria
- At least 3 commits per feature branch with clear messages
- Feature branches pushed to GitHub and visible in repository history
- Commits: Each commit has a descriptive message following conventional format
- Branching: Feature branches created with clear naming; multiple commits per branch demonstrate workflow
