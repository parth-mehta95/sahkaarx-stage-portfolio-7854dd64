# Set Up Virtual Environment for Data Science Project

## Task Brief
Create and configure a virtual environment for your capstone project; install dependencies and document setup in requirements.txt.

## Scenario
Your data team needs reproducible project setup. Create a venv, install dependencies, and document the process for team members.

## Deliverables
- Configured virtual environment with requirements.txt
- Setup documentation in project README

## Success Criteria
- venv activates cleanly on fresh clone
- All project imports work after pip install -r requirements.txt
- README includes step-by-step activation and installation instructions
- Virtual Environments: Virtual environment created and activated without errors
- Virtual Environments: requirements.txt lists all project dependencies with pinned versions
- Virtual Environments: Setup instructions documented and reproducible
